Watching a SAT solver think

A SAT solver takes a pile of or-clauses and tries to make every one of them true at once. This page replays one solving step by step. Most steps are boring: the solver guesses a value, and then the clauses force a few more. The interesting moment is a conflict. The solver traces the conflict back to the guesses that caused it, writes down a new clause so it never repeats that mistake, and jumps back past every guess that wasn't to blame.

Use → to step, space to play, c to skip to the next conflict.

DIMACS format: one clause per line, ending in 0. Name a variable with a line like c var 3 rain.

Implication graph

One row per guess (a "decision level"). Thick outline = a guess. Arrows run from the values that forced an assignment. Highlighted nodes are the ones in the clause being built. Gold is where the analysis stops (the first UIP).
