CDCL step by step

A replay of my SAT solver on small formulas. Code is on GitHub.

A SAT solver is given a list of clauses (each one is an "or" of some variables, possibly negated) and looks for true/false values that make all of them true. This page goes through one run a step at a time. The solver guesses a value, works out what that guess forces, and repeats. When some clause ends up with every literal false, it works out which guesses caused that, adds a new clause that rules them out, and backs up.

DIMACS format: one clause per line, ending in 0. Name a variable with a line like c var 3 rain.

Keyboard: ← and → to step, space to play, c for the next conflict.

This page runs a small JavaScript copy of the C++ solver. It's written to be easy to follow rather than fast (it scans every clause instead of using watched literals), and it's tested against the C++ solver on a thousand random formulas.
