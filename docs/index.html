The algorithm

  1. Decide: guess a value for an unassigned variable.
  2. Propagate: a clause with one unassigned literal left and the rest false forces that literal.
  3. Conflict: some clause has every literal false.
  4. Analyze: resolve the conflict clause with the clauses that forced its literals, until one literal from the current level remains.
  5. Learn and backjump: add that clause, undo to the level where it becomes unit, and continue.
