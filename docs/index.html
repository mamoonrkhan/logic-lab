CDCL step by step

A replay of my SAT solver on small formulas. Code is on GitHub.

Say you're planning a party with some rules: Alice or Bob has to come. If Bob comes, Dave comes too. Alice and Carol can't both come. Is there a guest list that follows every rule? With six friends you could work it out on paper. With a million "friends", you need a program. That program is called a SAT solver, and real ones handle problems like scheduling, checking computer chips for bugs, and working out which software versions are compatible.

This page replays a solver working through a puzzle, one step at a time. It does three things over and over:

  1. Guess something it doesn't know yet ("say Alice stays home").
  2. Follow the rules to see what that forces ("then Bob has to come, so Dave has to come").
  3. If a rule gets broken, figure out which guesses caused it, write down a new rule so it never makes that mistake again, and back up.

What the solver knows (the implication graph)

A map of what the solver knows and why. Each box is a fact. Boxes with a thick blue outline are guesses. Each row is a level: how many guesses deep the solver was when it learned that fact. An arrow means "this fact helped force that one". When a rule breaks, the boxes being blamed turn yellow.

The rules (clauses)

Every rule, written as a list of options joined by ∨ ("or"). At least one option in each rule has to be true. green = true, red = false, grey = not decided yet. Rules the solver learned (L1, L2, …) come first. Hover over a rule to see it in words.

What do the words on this page mean?
variable
Something that's either true or false, like "Alice comes to the party".
literal
A variable or its opposite: "Alice comes" or "Alice doesn't come" (written ¬Alice or "no Alice").
clause (rule)
A list of literals joined by "or". It's followed if at least one of them is true.
forced (unit propagation)
When every option in a rule is ruled out except one, that last one has to be true.
level
Which guess a fact came from. Facts on level 3 depend on the third guess.
conflict
A rule where every option has been ruled out. Some guess was wrong.
resolution
Combining two rules into a new one that follows from both. It's how the solver works out a learned rule.
learned clause
A new rule the solver figured out from a conflict. It always follows from the original rules.
backjump
Undoing several guesses at once, back to the last one that actually mattered.
SAT / UNSAT
Satisfiable (some assignment follows every rule) or unsatisfiable (none does).

This page runs a small JavaScript copy of the C++ solver. It's written to be easy to follow rather than fast (it scans every clause instead of using watched literals), and it's tested against the C++ solver on a thousand random formulas.
